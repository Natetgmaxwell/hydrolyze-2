```
4 x 100 Broken @ 1:30 to 1:40 [R.I. :30]
#1 = 75 yds. + 25 yds; #2 = 50 + 50; #3 = 25 + 75; #4 = 100 yds. without a break.
Broken R.I. :05 as indicated.
```

```
#1 broken @ 100 for :10 @ 500 Race Pace
#2 broken @ each 50 for :10 @ 200 Race Pace
```

### Broken swim definition (SprintSalo glossary):
```
Broken R.I. :10
Broken rest interval found between different segments of a whole.
i.e. 50 yds. + 25 yds. Broken R.I. @ :10 @ 1:15.
Swimmer completes the 50 yds. then takes the Broken Rest Interval of :10 seconds.
Then the swimmer completes the 25 yds.
The entire interval for the 50 + 25 is 1:15.
```

### USMS broken swim example:
```
1 x 800, broken by 10 seconds rest at each 100, steady pace throughout
```

## 4. DESCENDING SETS

### SprintSalo descending:
```
9 x 50 I.M. Order @ 1:00 [R.I. :20]
Descend in sets of three.
Example: 9 x 50 has #1 = slow; #2 = medium; #3 = fast; 
#4 = slow; #5 = medium; etc.
```

```
Descend by 25's: The last 25 yards is the fastest time, the first 25 is the slowest time.
The finish time needed to complete the same distance is less, hence the numbers descend.
```

```
Pull - 3 x (3x50 + 100)
50's = Hold P200 + :05
100's = Descend 1 to 3 to P200 + :02
```
*(Source: SprintSalo, Practice #15)*

```
4 x (3x50 + 3x25)
50's @ C.I. and 25's @ :30 [R.I. :15]
50's broken R.I. :20 during which time the swimmer exits the pool 
to complete :10 seconds of triceps extension on a MiniGym.
Descend 25's.
```
*(Source: SprintSalo, Practice #18)*

## 5. PACE TARGETS (P100, P200, Race Pace, Base pace)

### SprintSalo pace notation:
```
P200 = Pace 200. The swimmer's end-of-season goal time used to figure GoalPace.
The total race time is divided into the matching segment desired.

Example: Goal time for 200 yard free is 1:50.00. That is 110 total seconds.
GoalPace for 25 yard distance (8 lengths) = 110 ÷ 8 = 13.75.

Holding P100 = Holding Pace 100's means the swimmers strive to repeat 
the pace 100 time in each of the swims in that set.
```

```
3 x (3x25 + 50) @ :40/1:00 [R.I. :20/:40]
Hold P100
```

```
3 x (3x50 + 75) @ H.R. 23
50's = Hold P100 + :05
75 = Hold P200.
```

```
3 x 50 @ H.R. 23 Holding P200
```

```
4 x (50 + 2x25 + 50)
#1 = 50 yds. holding P200;
#2 & #3 = 25 yds. Sprint;
#4 = 50 yds. holding P100 + :02.
```

### FasterSwimming race pace notation:
```
RP stands for race pace
VS stands for variable speed
FIP stands for fastest interval (send off) possible
```

```
Individualized Race Pace based on events you are swimming at champs!
complete the following:
  100 @ 500 RP @ 90%
  2 x 50 @ 200 RP @ 95%
  4 x 25 @ 100 RP @ 100%
  4 x 100 recovery swim on 1:40
```
*(Source: FasterSwimming, Week 7 Day 31)*

```
2 x 50 sprint on 1:15 boys sub :28 girls :31
```
*(Source: FasterSwimming, Week 5 Day 21)*

### Base pace notation (IJSPT swimming vocabulary):
```
Base: The pace a swimmer or group of swimmer can swim 100 yards 
repeatedly and still finish with 5-10 seconds rest.

5x100 yards base (1:30)
5x100 yards base +5 (1:35) allows for more rest (easier)
```

### SprintSalo Heart Rate targets:
```
H.R. 23: Heart Rate 23 is a term used in SprintSalo that dictates rest intervals.
Between swims the swimmer rests until his or her heart rate returns to 23 beats 
in a :10 second count. Recovery is individualized. Swimmers in better shape 
swim at a faster pace and need less rest.
```

```
8 x 50 @ H.R. 23 Each 50 is a maximum effort swim.
```

```
  + 0 points if they swam slower than P200
Team goal: 500 points across 25 swimmers.
```

## NOTATION KEY / GLOSSARY SUMMARY

| Notation | Meaning |
|----------|---------|
| `NxM @ T` | N repeats of M yards/meters on interval T |
| `[R.I. :XX]` | Rest Interval (alternative to send-off) |
| `Broken R.I. :XX` | Rest inserted between segments of a single broken swim |
| `P100` / `P200` | Pace for 100/200 (goal-time-derived target pace per repeat) |
| `RP` | Race Pace |
| `VS` | Variable Speed |
| `H.R. 23` | Heart Rate recovery target (23 beats per 10-sec count) |
| `Descend 1-3` | Each repeat gets faster within groups (1=slow, 2=med, 3=fast) |
| `Descend by 25's` | Last 25 of each repeat is fastest |
| `IM Order` | Fly → Back → Breast → Free |
| `C.I.` | Coaches Interval (coach says "go" rather than pace clock) |
| `Build` | Start gradual, finish at full speed |
| `base (1:30)` | 100-yd repeat pace with 5-10 sec rest |
| `3 x (3x50 + 100)` | 3 rounds; each round = three 50s then one 100 |

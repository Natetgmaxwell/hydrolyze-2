## Why

The stopwatch spine (V0.35–V0.42) makes the app a capture device. The Data Center makes it a *coaching* device: "the coach feels like they are levitating in terms of the amount of coaching insights they are receiving — all without the working memory overload" (user, 2026-06-23). The 0.5-second glance test: "The analytics view must answer the coach's question in 0.5 seconds, or it's noise."

## The proposed v1 signal (from the squad-level progression design, user-approved shape)

Per swimmer, one row, one signal, one color, one label — computed from existing + V0.40/V0.42 data:

| Signal | Meaning | Color | Coach action |
|---|---|---|---|
| "Race ready at 50 Free" | gap-to-PB < 2% at form event | 🟢 | pick for the meet |
| "Building at 50 Free" | gap 2–5%, improving trend | 🟡 | leave alone |
| "Off pace at 50 Free" | gap > 5%, declining trend | 🔴 | conversation this week |
| "Quiet at 50 Free" | no recent swims at event | ⚫ | check-in |

Tap → SwimmerAnalyticsView (exists). Zones (V0.40) and recovery signature (V0.42) fold in as detail-row content, never headline.

## Contract (if greenlit — slices)

### Slice 1 — Gear capture picker (the F-v unlock)
One-tap "Gear for this set?" before each set's timing starts (none / paddles / pull buoy / fins / parachute — the 5 options from the design original). recorded_times inherit gear. This is the precondition for the F-v map and the calibration that pairing already keys on. Small, independent, shippable alone.

### Slice 2 — Signal computation (pure Swift service)
`SquadSignalService`: per swimmer, per form event (best PB stroke+distance), compute gap-to-PB + trend from recorded_times (last 8 weeks), consume zones (V0.40) for "which zone are they training in" context, recovery signature (V0.42) for the detail row. Output: `SquadSignal { swimmerId, event, signal: .raceReady/.building/.offPace/.quiet, gapPercent, trendSlope }`. Unit-testable.

### Slice 3 — Squad view UI
New surface in AnalyticsTabView (or sibling): one row per swimmer, color dot + signal label + event, tap → existing SwimmerAnalyticsView. 0.5-second glance: name + color + 3-4 words. Never a number in the headline.

### Slice 4 — F-v squad map (v1.1 of this surface)
Scatter: x = gear (categorical, none→paddles→fins→parachute as resistance ordinal), y = per-100m pace at the swimmer's form event. Squad median + spread bands. Tap a dot → swimmer analytics. Only renders once gear data exists (hidden otherwise — never greyed out).

## Requirements (V0.40_SPEC.md §Slice 2 — pure, no DB, no async)

Add to `TrainingZoneService` (append — keep the service file the single home for zone logic) a static resolver:

`static func latestUsableProfile(profiles: [SwimmerTestProfile]) -> SwimmerTestProfile?`

Resolution rule (spec §Slice 2, approved decision #3):
- **Usable = latest profile per (swimmer, stroke) with `trial_number >= 2` and NO `learningTrial` quality flag.**
- `learningTrial` flag means `qualityFlags` contains `"learning_trial"`. Trials 1–2 are flagged learning (the analyzer appends `.learningTrial` when trialNumber <= 2), so a learning trial is NOT usable.
- Returns the profile with the highest `trialNumber` among the usable ones (i.e. "prefers the newest usable trial"). If multiple profiles share the same max trialNumber (rare — should not happen in practice), return the one with the most recent `testDate` (ISO8601 string; compare lexicographically — ISO8601 strings sort correctly chronologically).

Acceptance (spec §Slice 2):
- Returns nil for a swimmer with only trial 1 (or all trials learning-flagged).
- Returns the trial-2 profile when it exists.
- Prefers the newest usable trial (trial 3 beats trial 2 when both usable).

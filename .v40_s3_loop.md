## Requirements (V0.40_SPEC.md §Slice 3 — two per-swimmer surfaces, no new squad view)

### 3a. Zones on the 3MT review panel (`ThreeMTPanelView`)

Under the three numbers (`statsRow`), add a **zones section** showing the four zone paces in coach vocabulary. Use `TrainingZones.derive(...)` from the panel's `profile`. Requirements:

- The panel already receives `profile: SwimmerTestProfile`. Compute zones: `TrainingZones.derive(criticalSpeedMps: profile.criticalSpeedMps, peakSpeedMps: profile.peakSpeedMps, sourceTrialNumber: profile.trialNumber)`.
- Show four lines, one per zone, coach vocabulary only: `Steady: 1:12/100m`, `Easy: ...`, `Hard: ...`, `Sprint: ...`. Order: Easy, Steady, Hard, Sprint.
- **Learning trial** (`profile.qualityFlags` contains `"learning_trial"`) → zones section HIDDEN entirely. The existing `flagCopy` line already shows "Learning trial — repeat before using for zones"; do not duplicate — just don't render the zone lines.
- **No usable profile** → hidden (never greyed out). This panel only exists when a profile row is present, so the gate is: hide zones iff learning trial OR zones derive returns nil.
- Inline section, no modal, no new colors/fonts — match the existing statTile/flag copy styling. Coach vocabulary ONLY (Easy/Steady/Hard/Sprint). No "LT", no "critical speed", no "zone 1-4".

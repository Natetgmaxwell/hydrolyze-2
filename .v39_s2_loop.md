## Requirements (spec §Slice 2 — pure logic, no DB, no async)

Create `ios-native/Hydrolyze/Sources/Services/RestCountdownModel.swift` — a pure struct/class that is the drop-rule state machine. Model the spec's §Slice 2 + §4.1 of `docs/research/2026-08-15-3mt-drop-rule-zones.md`.

### State per swimmer
The model holds:
- `strikes: [String: Int]` — keyed by swimmerId; 1st strike, 2nd strike.
- `currentExtensionSec: [String: Int]` — per-swimmer current extension (0, 30, or 60).
- `standardMs: [String: Int]` — per-swimmer current standard (predicted or rep1).
- `standardSource: [String: StandardSource]` — where the current standard came from (`.predicted` or `.rep1`).

### Common clock + per-swimmer flags (approved v1)
- `baseRestSec: Int` — the set's base interval (from `interval_text`, parsed to seconds).
- `remainingSec: Int` — the live common countdown (starts at `baseRestSec`, decrements via `tick`).
- `extendedRestSec: Int` — the common rest AFTER extensions (base + the max extension among all swimmers... spec: "extendedRestSec (shared countdown)").
- The countdown shown is the common clock (`remainingSec`); each swimmer's flag shows their personal extension (`currentExtensionSec[swimmer]`).

### Drop rules (spec §Slice 2 rules 1-3)
1. **Evaluate on rep completion** — `func evaluate(swimmerId: String, repTimeMs: Int, distanceMeters: Int) -> DropEvaluation?`:
   - Standard = the caller-supplied predicted time **if maturity ≥ .reliable (6+ samples)**; else the caller-supplied rep1 time. The model does NOT call the predictor — the VM passes the standard + source in. Signature: `func evaluate(swimmerId: String, repTimeMs: Int, distanceMeters: Int, predictedStandardMs: Int?, predictionMaturity: Prediction.Maturity?, rep1TimeMs: Int) -> DropEvaluation?`.
     - If `predictionMaturity` is `.reliable` or `.excellent` and `predictedStandardMs != nil` → standard = predictedStandardMs, source = `.predicted`.
     - Else → standard = rep1TimeMs, source = `.rep1`.
   - Threshold = 0.5s (50m), 0.25s (25m) — **linear scaling by distance**: `thresholdMs = distanceMeters == 25 ? 250 : (distanceMeters == 50 ? 500 : Int(Double(distanceMeters) * 10.0))`. (Eva's rule: 0.5s per 50m, 0.25s per 25m → 10ms per meter.)
   - Strike if `repTimeMs > standard + threshold`.
     - If the swimmer **hits the standard again** (repTimeMs ≤ standard + threshold), **reset their strikes to 0** and currentExtensionSec to 0 (Eva: "he's allowed two strikes again").
   - On a strike: strikeCount for this swimmer increments (1 or 2). Strike 1 → extension +30s; strike 2 → extension +60s. Strike count caps at 2 (no further escalation).
   - Update `standardMs[swimmer]` and `standardSource[swimmer]` to the values used for THIS evaluation (always update these, even on a non-strike — the standard is per-evaluation).
   - Returns a `DropEvaluation` describing the decision (see below). Returns `nil` if no strike AND no state change is worth surfacing (no strike → return the evaluation too, with `struck = false`, so the VM can show "holding" flags — see Slice 3; but for the model, return a non-nil evaluation on EVERY rep completion so the VM always knows the current standard/strikes).
   - **Intensity gate**: the model does NOT evaluate if the set is not anaerobic. Add a property `setIsAnaerobic: Bool` set at init (or a parameter). When false, `evaluate` returns `nil` immediately (no evaluation — spec: "aerobic set → no evaluation"). The VM derives this from the set's intensity (hard/race).
2. **Common clock + per-swimmer flags**: after extensions, the common `extendedRestSec` = `baseRestSec + max(currentExtensionSec.values)` (max of all swimmers' extensions; 0 if none). `remainingSec` counts down from `extendedRestSec`.
3. **Revert** — `func revert(swimmerId: String)`: set `currentExtensionSec[swimmer] = 0`, `strikes[swimmer] = 0`, and recompute `extendedRestSec` (now = base + max of remaining extensions). Returns a `RevertResult` (the new extendedRestSec + that this event should be recorded with `reverted = true`).

### Model shape
```swift
enum RestStandardSource: String, Equatable, Sendable {
    case predicted
    case rep1
}

struct DropEvaluation: Equatable, Sendable {
    let swimmerId: String
    let repIndex: Int            // the rep being evaluated (1-indexed)
    let repTimeMs: Int
    let standardMs: Int
    let standardSource: RestStandardSource
    let baseRestSec: Int
    let extendedRestSec: Int     // AFTER this evaluation (post any strike)
    let deltaSec: Int            // 30, 60, or 0
    let strikeCount: Int         // current strike count for this swimmer after evaluation
    let struck: Bool             // true if this rep was a strike
}

struct RevertResult: Equatable, Sendable {
    let swimmerId: String
    let newExtendedRestSec: Int
    let reverted: Bool           // always true
}

final class RestCountdownModel {
    init(baseRestSec: Int, setIsAnaerobic: Bool)
    var strikes: [String: Int]
    var currentExtensionSec: [String: Int]
    var standardMs: [String: Int]
    var standardSource: [String: RestStandardSource]
    var remainingSec: Int        // live common countdown
    var extendedRestSec: Int     // recomputed on every extension change
    func evaluate(...) -> DropEvaluation?
    func revert(swimmerId: String) -> RevertResult
    func tick()                  // decrement remainingSec by 1, floor at 0
    func reset()                 // all swimmers cleared, remainingSec back to baseRestSec
}
```

- `init(baseRestSec: Int, setIsAnaerobic: Bool)` sets `extendedRestSec = baseRestSec`, `remainingSec = baseRestSec`.
- `tick()` decrements `remainingSec` by 1, floor 0 (the VM calls it once per second from its 10ms timer — Slice 3).
- `reset()` clears per-swimmer state and resets the clock to `baseRestSec`.

**Constraint: pure function — NO DB calls, NO async, NO UIKit, NO Combine in this file.** It only mutates its own state.

### Test cases (spec §Slice 2 Acceptance — ALL must be covered)
1. **strike on 50m rep > standard + 0.5s**: rep1Time 60.0s → standard 60000ms; a rep of 60.7s (60700ms) strikes (60.7 > 60.0+0.5). `struck == true`, `deltaSec == 30`, `strikeCount == 1`, `extendedRestSec == base + 30`.
2. **no strike within threshold**: rep of 60.4s (60400ms) does NOT strike (60.4 ≤ 60.0+0.5). `struck == false`, `deltaSec == 0`, `extendedRestSec == base`.
3. **second strike escalates +60s**: two consecutive strikes → second has `strikeCount == 2`, `deltaSec == 60`, `extendedRestSec == base + 60`.
4. **strike reset on good rep**: after a strike, a good rep (≤ standard+threshold) resets strikes to 0 and extension to 0; a subsequent strike is again `strikeCount == 1`, `deltaSec == 30`.
5. **immature prediction falls back to rep 1**: predictionMaturity `.learning` (or `.none`) → standard = rep1TimeMs, `standardSource == .rep1`. With `.reliable` + a predicted standard → `standardSource == .predicted` and standard = the predicted value.
6. **aerobic set → no evaluation**: `setIsAnaerobic: false` → `evaluate` returns nil (no strike evaluation at all).
7. **revert restores base rest**: after a strike (extendedRestSec = base+30), `revert(swimmerId:)` → `newExtendedRestSec == base`, `reverted == true`, strikes back to 0.
8. **tick decrements + floor 0**: `tick()` three times from baseRestSec 2 → remainingSec 1, 0, 0 (floor).
9. **25m threshold is 0.25s**: a 25m rep 0.3s over standard strikes; 0.2s over does not.
10. **linear scaling for odd distance**: a 100m rep 1.0s over standard strikes (100 × 10ms = 1000ms threshold); 0.9s over does not.

Also a **multi-swimmer** case (spec's "Ariana +30s, Jack holding"): swimmer A strikes (+30), swimmer B does not (holding) → `currentExtensionSec[A] == 30`, `currentExtensionSec[B] == 0`, `extendedRestSec == base + 30`. Then swimmer A strikes again (+60) → `extendedRestSec == base + 60`.
